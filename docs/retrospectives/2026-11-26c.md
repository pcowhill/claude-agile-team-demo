## Went poorly

**A component's changed contract broke a caller the PR did not look at.**
#1016 (for #967) made `ClipThumbnail` render a pending box instead of
nothing, so a timeline row keeps its height while a frame is captured.
The author grepped for test ids and found only the timeline.
`git grep -n "ClipThumbnail" -- src` also finds the media library's video
card. Its comments say ClipThumbnail "renders nothing until it resolves".
Its glyph placeholder (#311) relied on that, and it showed a black square
instead. The review found it with that grep. The fix (`f8342e5`) made the
reviewer a co-author, so #1016 needs another reviewing session. The rule
from #934 asks for this grep when a *kind* widens. A changed pending state
is not a kind. Proposed as **#1019**.

**A measurement waited on an assumption about the container.** #748's
recurrence comment, at 07:31, named the measurement and routed it through
#779's CI dispatch because "the container has no Playwright Firefox". This
session's container had one, as the last retrospective also found. The
measurement took about 10 min once someone tried it, 15 hours later. There
is no rule to change: `E2E_FIREFOX=1` is the check, and it costs a single
command.

## Changes proposed

- **#1019:** a PR that changes what a shared component or function renders
  or returns in a state its callers can see greps its callers, as a widened
  kind does. `review.md`'s step gains the same clause.
