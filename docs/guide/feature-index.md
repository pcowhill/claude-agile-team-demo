# Feature Index

Every control, menu item, setting, dialog and keyboard shortcut in the editor, in one alphabetical list, each linking to the page that explains it. Entries read as the label reads on screen, so a control you have just seen can be looked up by the words beside it. A control drawn as a glyph alone — **↑**, **✕**, **⋯** — is listed under [Symbols and keys](#symbols-and-keys) with what it does in brackets.

Keyboard combos are listed by the combo itself (**Ctrl+S**, **F1**, **Space**), in their own alphabetical place; [Keyboard shortcuts](keyboard-shortcuts.md) has all of them as one table, with the step sizes you chose.

This list is checked against the running editor in CI: a control the app shows and this page does not name fails the build. It names controls; what each one *does* is on the page it links to.

## Symbols and keys

- **+ Effect** — an expanded sequence entry, below its fields. [Timeline › + Effect ▾](timeline.md#effect)
